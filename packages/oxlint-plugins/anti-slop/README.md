# anti-slop (vendored)

Vendored copy of [dmmulroy/anti-slop](https://github.com/dmmulroy/anti-slop) — opinionated
Oxlint rules that reject low-evidence TypeScript and JavaScript patterns.

This directory is maintained as a vendored subtree inside `@workspace/oxlint-plugins`.
Oxlint registers it as the `anti-slop` jsPlugin (`anti-slop/<rule-name>` rule IDs).
