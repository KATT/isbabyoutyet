# Vendored Anti-Slop rules

Source: <https://github.com/dmmulroy/anti-slop>

Revision: `6d538555cb151d4121ed51a27db81890eacf8ae9`

Rules and shared helpers live as siblings under `oxlint-plugins/` (same place as
the repo's other Oxlint plugins). `anti-slop.ts` registers the rules that have
been landed so far; later stack PRs add one sibling rule file at a time.

The sources are vendored under the accompanying MIT license (`ANTI_SLOP_LICENSE`).
