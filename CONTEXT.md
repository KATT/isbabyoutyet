# Is Baby Out Yet

Parents share a public page so friends and family can follow a baby's journey
and send encouragement.

## Language

**Baby page**:
The shareable page that tracks one baby's journey from due date through birth.
_Avoid_: Listing, profile, event

**Owner**:
The person who created the baby page. Only they can delete it or manage who
else can administer it.
_Avoid_: Creator (except when describing the act of creation), primary parent

**Co-parent**:
Someone the owner has authorized to manage a baby page — posting updates,
changing settings, and moderating encouragements — but not deleting the page
or managing other co-parents.
_Avoid_: Administrator, collaborator, member, editor (except in generic UI
copy that pairs with co-parent)

**Update**:
A message and/or photo the owner or a co-parent posts to the baby page feed,
optionally marking a milestone.
_Avoid_: Post (except as a verb), status update

**Encouragement**:
A message a visitor leaves on a baby page.
_Avoid_: Comment, well-wish

**Demo source**:
A seeded, read-only baby page that visitors can explore and use as the starting
point for a playground baby.
_Avoid_: Demo baby (ambiguous), template

**Playground baby**:
An editable, temporary copy of a demo source, owned by one browser visitor and
automatically removed after its trial period.
_Avoid_: Demo baby (ambiguous), clone

**Soft delete**:
Marking a record deleted while keeping it recoverable, instead of removing it
from the database.
_Avoid_: Archive (unless we later add a distinct archive concept), hard delete
(for the product default)
